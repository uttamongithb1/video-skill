Bhai, kabhi socha hai Tor Browser tumhari identity hide kaise karta hai? Tum website open karte ho, lekin tumhari request seedha website tak nahi jaati!
Instead, Tor apne network se teen computers select karta hai — Guard Node, Middle Node aur Exit Node. Aur in teeno se milkar banta hai tumhara secret route!
Ab tumhari request encrypt hoti hai teen layers mein, bilkul ek ke andar ek rakhe teen envelopes ki tarah! Har computer sirf apni encryption layer remove karta hai aur request aage bhej deta hai.
Guard ko tumhara real IP pata hota hai, lekin destination nahi. Middle ko sirf apne previous aur next computer ka pata hota hai. Aur Exit ko website ka address pata hota hai, lekin tumhara real IP nahi!
Finally, Exit Node website se connect karta hai. Isliye website ko tumhara real IP nahi, Exit Node ka IP address dikhta hai. Aur response bhi isi route se wapas aata hai!
